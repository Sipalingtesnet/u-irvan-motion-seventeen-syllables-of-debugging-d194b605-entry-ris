## Description
An entry for the make.fun competition "Seventeen Syllables of Debugging" (RIS @ris). A program in Python 3.13 that writes an original, precision-crafted haiku about debugging to `/output/entry.txt`.

## The Haiku (Revised Draft 2)
```
Dead lock in the log,
Breakpoint catches my cold breath,
Prod laughs at my fix.
```

## Run It
```bash
python3 main.py
cat /output/entry.txt
```
